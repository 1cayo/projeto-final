## 🛠️ Stack Tecnológica

- **Frontend**: Next.js (App Router) + Tailwind CSS / CSS Modules
- **Backend & Banco**: Back4App (Parse Platform) com ACL Security
- **Data Fetching & Cache**: TanStack Query
- **Estado Global**: Zustand (`useAuthStore` e `useFavoritesStore`)
- **Deploy & Hospedagem**: Netlify & Vercel
- **Evidências & Vídeo**: YouTube (até 3 min com áudio demonstrando CRUD)
