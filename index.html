Stack & Arquitetura do Sistema

Arquitetura moderna, escalável e desacoplada, utilizando Next.js no frontend e Parse Server na nuvem.

Frontend & Estilização
Next.js 14+ com App Router para roteamento moderno, componentes de servidor/cliente e Tailwind CSS ou CSS Modules para design responsivo.
Next.js (App Router) Tailwind CSS
Backend & Persistência
Back4App (Parse Platform) como BaaS gerenciado com ACL (segurança e permissões por objeto) e integração via Parse JavaScript SDK.
Back4App (Parse) ACL Security
Estado Global & Cache
TanStack Query para controle de cache, mutações e revalidação de dados. Zustand para estado de sessão e favoritos persistentes.
TanStack Query useAuthStore useFavoritesStore
Infra, CI/CD & Evidências
Hospedagem automatizada na Vercel com variáveis seguras, repositório GitHub com branch protection e vídeo demonstrativo de até 3 minutos no YouTube.
Vercel GitHub YouTube

5. Regras de Convivência

Acordos de trabalho em equipe para evitar penalidades
1
Commits Frequentes e Individuais

Cada integrante commita o próprio trabalho em commits pequenos e frequentes, comprovando a participação ativa no repositório.

2
Branches e Pull Requests Cruzados

Uma branch por tarefa (feature/nome-tarefa) com PR revisado por outro colega da equipe que não esteja com tarefa aberta.

3
Daily Rápida de 10 minutos

Comunicação diária no grupo respondendo 3 perguntas: (1) O que fiz, (2) O que vou fazer e (3) Se estou travado.

4
Prazo Interno & Ajuda Mútua

Se uma tarefa passar 1 dia do prazo estipulado, o time se mobiliza imediatamente para ajudar a destravar sem atrasar as entregas.

5
Definição de Pronto (DoD)

Funciona no Vercel, código mergeado no GitHub, CSS revisado e no mínimo 2 objetos válidos cadastrados no Back4App.
